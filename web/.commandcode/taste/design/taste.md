# Design Preferences

- Prefers flat, minimalist UI (inspired by minimalist web-dev aesthetics) with subtle shadows and avoids heavy gradients. Confidence: 0.85
- Prefers clean, professional sans-serif fonts such as Inter. Confidence: 0.8
- Values mobile-responsive layouts using Tailwind's sm/md/lg breakpoints. Confidence: 0.85
- Values accessibility: aria-labels/aria-expanded on interactive elements and strong color contrast. Confidence: 0.9
- Prefers professional, authoritative color palettes — currently a deep emerald-green primary with an orange secondary accent (explicitly requested green/orange, superseding the earlier indigo/royal-blue). Confidence: 0.9
- Prefers rounded corners on UI elements (e.g., rounded-lg for buttons/inputs, rounded-xl for cards, rounded-2xl for large panels/mockups). Confidence: 0.85
- Dislikes "vibe coded" / rainbow multi-color accents; prefers a restrained, limited palette (e.g., green primary + orange accent). Confidence: 0.9
- Values smooth, tasteful animations and visual polish (scroll reveals, staggered entrances, animated counters) to create a "wow" impression, and explicitly asks for "wow" landing pages. Confidence: 0.9
- Prefers visualizing data with graphs/charts rather than plain text or progress bars. Confidence: 0.7
- Prefers hover micro-interactions on cards and stat numbers (lift + tinted border + number color shift) using Tailwind group-hover transitions. Confidence: 0.75
- Prefers interactive data visualizations (hover tooltips, metric switchers/segmented controls) over static charts. Confidence: 0.8
- Enjoys subtle infinite looping micro-animations (e.g., a small pulsing/bouncing dot on badges or status indicators) to add constant life to the page. Confidence: 0.7
- Prefers "heart monitor"/ECG-style pulse-line animations — a dot traveling along a waveform path — for live/status indicators, rather than a pulsing/bouncing dot sitting in place. Confidence: 0.8
