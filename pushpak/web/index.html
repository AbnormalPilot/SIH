Methodological sensitivity

The headline index is fixed-base, arithmetic and seasonally unadjusted, because those properties make it checkable by hand. Every alternative is compiled from the identical quotes and shown beside it, so the cost of each choice is a measured number rather than a claim.

Operations

A pipeline that fails quietly keeps publishing plausible numbers from stale data. Jobs retry on an explicit backoff; when the last attempt fails, an alert is raised rather than logged and forgotten.

Reconstruct the latest index by hand

Each cell's contribution = weight × (price ÷ base price) × 100. The contributions sum to the published number.

Pushpak is a hackathon prototype, not an official statistic. Route weights are derived from the DGCA domestic city-pair passenger release; advance-purchase weights are a documented assumption. See /api/v1/methodology and /api/v1/provenance.
